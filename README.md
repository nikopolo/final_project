# Планировщик задач

## Описание проекта

Это веб-приложение для задач, которые могут повторяться по заданному правилу: ежегодно, через какое-то количество дней, в определённые дни месяца или недели.

Возможности ресурса:

1. Добавление, редактирование, удаление задач.
2. Получение списка задач.
3. Отмечать задачи как выполненные.
4. Получение и изменение параметров задач.

## Сборка проекта

    go build -o task_scheduler .

## Запуск через Docker

    set GOOS=linux
    set GOARCH=amd64
    set CGO_ENABLED=0
    go build -o task_scheduler .
    docker build -t task_scheduler .
    docker run -d -p 7540:7540 task_scheduler
    перейти по адресу: http://localhost:7540
